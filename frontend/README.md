# HomeHub — frontend

React + Vite + TypeScript. Vedi il [README del repo](../README.md) e [ARCHITECTURE.md](../ARCHITECTURE.md) per contesto, quickstart e wireframe.

```bash
npm install
npm run dev
```

Il dev server proxya `/api` verso `http://localhost:8000` (vedi `vite.config.ts`) — niente `.env` da creare a meno di voler puntare a un backend diverso.
